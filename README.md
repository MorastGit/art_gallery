## Собственный проект

Тема проекта: Картинная галерея

Главный класс: Art

Почему этот объект нужен программе:
Класс описывает картину и содержит в себе обязательные для любой картины данные


Какие данные хранит объект:

- Название
- Автор
- Год
- Месторасположение картины (по умолчанию в нашей галерее)

Какие значения задаются через конструктор:
- Название
- Автор
- Год

Какие значения можно задавать автоматически:
- Месторасположение картины

Какое значение я решил задавать автоматически и почему?
- Месторасположение картины в нашей галерее.
Задается автоматически потому что все созданные картины по умолчанию расположены в нашей галерее.

## Практическая работа №2

Добавлено:
- Метод ChangePlace который позволяет менять месторасположение картины
- Метод ChangeYear который позволяет менять год выпуска картины (не принимает год выпуска больше 2026)
- До этого уже было в классе Art метод Print который позволяет вывести информацию о картине на экран. В этой лабе он был изменен. Добавлен вывод месторасположения картины и более красивый вывод данных.

### Поведение главного класса

- Метод 1: ChangePlace(place)
Меняет месторасположение картины на place
- Метод 2: ChangeYear(year)
Меняет год выпуска картины на year
- Метод 3: GetDescription()
Возвращает строку с информацией о картине. Не выводит в терминал.

- Почему эти действия относятся именно к этому классу:
Потому что они находятся в блоке класса Art и поэтому можно их вызвать только из этого класса созданного объекта.
